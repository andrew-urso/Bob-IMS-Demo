# IMS DBA Capability Suite — Bob for Z Demo

This project lets Bob for Z act as an IMS DBA assistant. Bob connects to a live IMS system over JDBC, discovers database metadata, executes DDL, and helps you query, create, update, and edit IMS databases — all through natural-language conversation.

## Prerequisites

| Requirement | Notes |
|---|---|
| Java 17+ | `java -version` to verify |
| Apache Maven 3.8+ | `mvn -version` to verify |
| IMS JDBC driver (`udb-15.165.jar`) | Must be installed in local Maven repo (see below) |
| Access to an IMS Connect server | TCP/IP reachable from your workstation |
| `curl` + `jq` | Required only for `run-catimp.sh` |

### Install the IMS JDBC Driver

The IMS Universal JDBC driver is not in Maven Central. Install it manually:

```bash
mvn install:install-file \
  -Dfile=/path/to/imsudb.jar \
  -DgroupId=com.ibm.ims \
  -DartifactId=udb \
  -Dversion=15.165 \
  -Dpackaging=jar
```

Replace `/path/to/imsudb.jar` with the actual path to your IMS JDBC driver JAR (typically found in your IMS installation or IBM support download).

## Configuration

All connection properties live in one file:

**[`Java_Programs/src/main/java/com/ibm/ims/jdbcbob/IMSConnectionConfig.java`](bob-demo/Java_Programs/src/main/java/com/ibm/ims/jdbcbob/IMSConnectionConfig.java)**

```java
public static final String HOST     = "172.19.3.3";  // IMS Connect hostname / IP
public static final int    PORT     = 5555;           // IMS Connect port
public static final String USER     = "IBMUSER";      // RACF user ID
public static final String PASSWORD = "yourpassword"; // RACF password

public static final String DDL_PSB  = "DFSCP001";    // PSB for DDL operations

public static final String ZOSMF_HOST     = "172.19.3.3"; // z/OSMF hostname / IP
public static final int    ZOSMF_PORT     = 10443;         // z/OSMF port
public static final String ZOSMF_USER     = "IBMUSER";     // z/OSMF user
public static final String ZOSMF_PASSWORD = "yourpassword";// z/OSMF password
```

Update these values to point at your IMS system, then rebuild:

```bash
cd bob-demo/Java_Programs
mvn compile
```

## The Four Workflows (Bob's Capabilities)

Bob routes every request to one of four workflows based on what you ask:

| # | What you want to do | Workflow |
|---|---|---|
| 1 | **Query data** — "show me all entries in DFSIVP37 with last name Smith" | `WORKFLOW_1_NLP_QUERY.md` |
| 2 | **Create a new database** — "create an IMS DEDB called ORDERDB" | `WORKFLOW_2_DATABASE_CREATION.md` |
| 3 | **Alter an existing database** — "add a phone number column to PARTROOT" | `WORKFLOW_3_UPDATE_DATABASE.md` |
| 4 | **Edit fields / sync from a COBOL copybook** — "here is my copybook, sync it to DFSSAM09" | `WORKFLOW_4_DATABASE_EDITOR.md` |

The master routing document [`workflows/BOB_WORKFLOW_PROCESS.md`](bob-demo/workflows/BOB_WORKFLOW_PROCESS.md) explains how Bob classifies each request and which workflow it follows.

## Running Programs Manually

All `mvn exec:java` commands are run from the `Java_Programs/` directory.

### Discover database metadata
```bash
cd bob-demo/Java_Programs
mvn exec:java -Dexec.mainClass="com.ibm.ims.jdbcbob.IMSMetadataExplorer" \
  -Dexec.args="DFSIVP37"
```

### Execute a SQL query
```bash
mvn exec:java -Dexec.mainClass="com.ibm.ims.jdbcbob.IMSQueryExecutor" \
  -Dexec.args="DFSIVP37 \"SELECT * FROM PHONEAP.PHONEBOOK WHERE LASTNAME = 'Smith'\""
```

### Execute a DDL file
```bash
mvn exec:java -Dexec.mainClass="com.ibm.ims.jdbcbob.IMSDBAExecutor" \
  -Dexec.args="CREATE ../context_and_examples/ddl-output/MYDB_create_20260101_120000.sql"
```

### Trigger IMS Catalog import
```bash
cd bob-demo/scripts
./run-catimp.sh
```
> Requires `ZOSMF_USER` and `ZOSMF_PASSWORD` to be set in environment or in a `.env` file at the project root.

## Credentials & Security

- **Never commit credentials.** The `.env` file is listed in `.gitignore`.
- Store your credentials in `bob-demo/.env`:
  ```
  ZOSMF_USER=IBMUSER
  ZOSMF_PASSWORD=yourpassword
  ```
- For the Java programs, update `IMSConnectionConfig.java` directly on your local machine — do not push that file with real passwords to a shared repository.
